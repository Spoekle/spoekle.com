# Setup Images

This directory contains photos of various hardware setups displayed on the About page.

## Required Images

Add your setup photos to this directory with the following names:

- `main-setup.jpg` - Your main PC/desktop setup
- `laptop1.jpg` - First laptop (Asus ROG Strix G15)
- `laptop2.jpg` - Second laptop (Macbook Air 2022)
- `server.jpg` - Server setup
- `camera.jpg` - Camera and photography gear

## Image Guidelines

- **Format**: JPG, PNG, or WebP
- **Recommended size**: 1600x1200px or similar aspect ratio
- **File size**: Keep under 500KB for optimal loading
- **Aspect ratio**: 4:3 or 16:9 works best

## Notes

- Images are optional - if an image file doesn't exist, only the specs will be shown
- Images will be automatically optimized by Next.js Image component
- The component uses responsive sizing, so images will scale appropriately on all devices
